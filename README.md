# Data Strukturları və Alqoritmləri — Vizual Tədris Layihəsi

Bu layihə universitetin **"Data Strukturları və Alqoritmləri"** fənni üçün hazırlanmış sadə, interaktiv və vizual tədris sistemidir.

Layihənin məqsədi əsas data strukturları və alqoritmlərin iş prinsipini həm nəzəri, həm də vizual olaraq sadə və aydın şəkildə nümayiş etdirməkdir.

## 📚 Əhatə Olunan Mövzular

1. **Array və List** — Sabit ölçülü massiv və dinamik siyahı
2. **Linked List** — Əlaqəli siyahı (Node əlavə etmə və göstərmə)
3. **LIFO (Stack)** — Yığın məntiqi (`push` və `pop`)
4. **FIFO (Queue)** — Növbə məntiqi (`enqueue` və `dequeue`)
5. **Deque** — İki tərəfli növbə (öndən və arxadan idarəetmə)
6. **Hash Table** — Açar-dəyər cütləri və sadə hash funksiyası
7. **Bucket Sort** — 0–100 arası balların səbətlərə bölünərək sıralanması
8. **Min-Heap** — Tam ikili ağac (Complete Binary Tree) üzərində minimum yığın
9. **Ağac Gəzişləri** — İkili axtarış ağacında (BST) Preorder, Inorder və Postorder rekursiv gəzişləri
